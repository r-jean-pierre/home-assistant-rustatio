# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in the Rustatio Home Assistant
integration, please do not report it through a public GitHub issue.

Use GitHub's private vulnerability reporting feature for this repository
instead.

Please include, when possible:

- A description of the vulnerability
- Steps to reproduce it
- The affected version of the integration
- The affected Home Assistant version
- Any relevant logs or technical details

Security reports will be reviewed as soon as reasonably possible.

## Supported versions

Security fixes are provided for the latest released version of the integration.

Users are encouraged to keep both the Rustatio integration and Home Assistant
up to date.
